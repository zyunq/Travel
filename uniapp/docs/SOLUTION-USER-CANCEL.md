## 如果选择器中没有文件

如果打开选择器后看不到任何文件，可能的原因：

### 原因 1：文件来源不对
```
✅ 可以看到：他人发送给你的文件（私聊或群聊）
❌ 看不到：自己发送到"文件传输助手"的文件
```

**解决方法**：让朋友发送一个测试文件给你

### 原因 2：文件格式不对
```
✅ 可以看到：.xlsx, .xls 文件
❌ 看不到：其他格式的文件（如 .pdf, .doc, .txt）
```

**解决方法**：确保文件是 Excel 格式

### 原因 3：文件太久远
```
✅ 可以看到：最近收到的文件
❌ 看不到：很久以前的文件（微信已清理缓存）
```

**解决方法**：让发送者重新发送文件

### 原因 4：开发者工具限制
```
⚠️ 微信开发者工具可能显示不出文件
✅ 在真机上测试可以看到所有符合条件的文件
```

**解决方法**：使用真机调试
