# 微信小程序文件导入问题解决方案

## 问题描述

小程序使用 `uni.chooseMessageFile` 读取微信聊天记录中的历史文件时失败。

## 根本原因

### 1. 权限配置缺失
`manifest.json` 中的 `requiredPrivateInfos` 缺少 `chooseMessageFile` 权限声明。

**已修复**：已在 manifest.json 中添加权限：
```json
"requiredPrivateInfos": ["chooseAddress", "getLocation", "chooseMessageFile"]
```

### 2. 微信 API 限制

`wx.chooseMessageFile` API 有以下严格限制：

#### ✅ 可以选择的文件
- 他人发送给您的文件（私聊）
- 群聊中他人发送的文件
- 最近接收的文件（微信未清理缓存）

#### ❌ 无法选择的文件
- 自己发送到"文件传输助手"的文件
- 时间过久的历史文件（微信已清理缓存）
- 已被发送者撤回的文件
- 已过期的文件

### 3. 常见错误及解决方案

| 错误信息 | 原因 | 解决方案 |
|---------|------|---------|
| `no permission` | 权限不足 | 删除小程序后重新进入，允许访问聊天记录权限 |
| `file not found` | 文件不存在或已过期 | 让发送者重新发送文件 |
| `Invalid file` | 文件格式不支持 | 确保文件是 .xlsx 或 .xls 格式 |
| `chooseMessageFile:fail` | 通用失败 | 检查文件是否在聊天记录中，是否被清理 |

## 使用建议

### 方案 1：通过聊天记录导入（推荐用于移动端）

1. 让他人将 Excel 文件发送给您（或发送到群聊）
2. 打开小程序，点击 "+" 按钮
3. 输入团名，选择行程类型
4. 点击"从聊天中选择 Excel"
5. 从聊天记录中选择该文件

**注意事项**：
- 不要使用"文件传输助手"中的文件
- 文件不要太久远，微信会定期清理缓存
- 如果选择失败，请让发送者重新发送文件

### 方案 2：通过网页端导入（推荐用于大量数据）

1. 访问网页端：https://api.zyqing.xyz
2. 登录账号
3. 在网页端直接上传 Excel 文件
4. 数据会自动同步到小程序

**优点**：
- 不受微信文件限制
- 支持更大的文件
- 更稳定的上传体验

## 测试步骤

1. 重新编译小程序：`npm run dev:mp-weixin`
2. 在微信开发者工具中删除旧的小程序
3. 重新打开小程序，允许访问聊天记录权限
4. 让他人发送一个 Excel 文件给您
5. 尝试在小程序中选择该文件
6. 验证文件是否能正常导入

## 如果问题仍然存在

如果按照以上步骤操作后问题仍然存在，请检查：

1. **微信版本**：确保微信版本 >= 8.0.0
2. **小程序基础库版本**：确保基础库版本 >= 2.10.0
3. **文件大小**：确保文件不超过 50MB
4. **文件格式**：确保是标准的 .xlsx 或 .xls 格式
5. **网络连接**：确保网络连接正常

如果所有方法都无效，建议使用网页端导入数据。
